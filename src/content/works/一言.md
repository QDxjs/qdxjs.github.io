## 把网页的一角，留给一句话

「一言 · 全站通用版」是一款浏览器用户脚本。安装后，它会在普通网页的顶部或底部显示一句来自 [Hitokoto（一言）](https://hitokoto.cn/) 的随机文字：可能是诗词、文学片段、动画台词，也可能是一句不着边际的抖机灵。

它不改动网页原有内容，只在页面上增加一条轻量的悬浮栏。平时单击悬浮栏即可换一句，右键便能打开设置；显示位置、刷新间隔、文字分类、背景、透明度、毛玻璃效果以及生效站点，都可以在面板中调整。

当前版本为 **2.4**，适合希望在日常浏览中偶遇一些文字，又不愿安装一整套新标签页或桌面应用的人。

## 功能一览

- 在所有普通 HTTP / HTTPS 网页上显示一言
- 支持动画、漫画、游戏、文学、原创、网络、其他、影视、诗词、哲学、抖机灵共 11 种分类
- 单击立即换句，可设置 0—3600 秒自动刷新；设为 0 时仅手动换句
- 顶部或底部显示，支持字号、透明度、背景色、背景透明度、模糊、边距与最大宽度调整
- 可选择是否显示出处，以及是否启用切换动画
- 提供全站、白名单、黑名单三种站点匹配模式，域名规则支持 `*` 通配符
- 设置保存在用户脚本管理器的本地存储中，保存后立即生效
- 对常见单页应用（SPA）的内容重绘进行监测，悬浮栏被移除后会尝试自动恢复
- 请求并发锁、8 秒超时和内容转义，避免重复请求与不安全的 HTML 注入

## 安装前需要什么

这不是一个独立应用，而是一段需要由“用户脚本管理器”运行的 JavaScript。请先在浏览器中安装下列任意一种扩展：

- **Tampermonkey（篡改猴）**：适用于 Chrome、Edge、Firefox 等主流桌面浏览器
- **Violentmonkey（暴力猴）**：同样支持常见的 Chromium 与 Firefox 浏览器

移动端能否使用，取决于你的移动浏览器是否支持扩展或用户脚本。脚本本身提供了小屏样式，但仍以桌面浏览器为主要使用环境。

## 三步完成安装

1. 安装并启用 Tampermonkey 或 Violentmonkey。
2. 点击本文标题下方的 **“下载”**，浏览器会打开 `hitokoto-universal.user.js`。脚本管理器应自动识别它并显示安装确认页。
3. 核对名称、版本和权限后点击安装，再刷新一个普通网页。页面上方默认会出现半透明的一言悬浮栏。

如果点击下载后只看到源代码，通常是脚本管理器尚未安装、未启用，或当前浏览器没有允许它接管 `.user.js` 链接。确认扩展状态后重新打开下载链接即可。

> 浏览器的新标签页、扩展商店、`chrome://`、`edge://`、`about:` 等内部页面通常禁止扩展注入脚本，因此不会显示一言。这是浏览器的安全限制，不是安装失败。

## 日常使用：三个动作就够了

### 单击悬浮栏：换一句

把鼠标移到一言悬浮栏上并单击，脚本会立即请求下一句话。请求期间显示“加载中…”，遇到网络错误、超时或数据解析失败时，悬浮栏会给出相应提示；再次单击即可重试。

脚本设有请求锁：上一条请求尚未结束时，连续点击不会产生多次并发请求。

### 右键悬浮栏：打开设置

在悬浮栏上单击鼠标右键，会阻止浏览器原本的右键菜单并打开“一言 · 设置”面板。完成调整后点击“保存”，效果立即应用，不需要刷新网页。

设置面板可以通过右上角关闭按钮、点击遮罩空白处或按 `Esc` 键关闭。点击“恢复默认”会立即写回默认配置。

### 从扩展菜单操作

打开浏览器工具栏中的用户脚本管理器，在本脚本的菜单中还可以找到：

- **一言设置**：打开可视化设置面板
- **换一句**：立即请求新句子
- **开关一言**：全局启用或关闭悬浮栏
- **在当前站点启用 / 禁用**：快速把当前域名加入规则，并切换到相应的白名单或黑名单模式

当悬浮栏被网页控件挡住、暂时不可点击，或你已经全局关闭它时，这组菜单尤其有用。

## 设置面板逐项说明

### 内容与刷新

- **启用一言**：脚本总开关。关闭后，当前悬浮栏会被移除，定时刷新也会停止。
- **句子分类**：从 11 个分类中选择一种；“全部分类”表示不向接口指定类别。官方已停用的网易云分类不在列表中。
- **自动刷新**：单位为秒，默认 30 秒。输入 `0` 表示关闭自动刷新，此时仍可单击手动换句。允许范围为 0—3600 秒的整数；空值、越界值或小数会提示错误，不会覆盖已保存设置。
- **显示来源**：开启后，在句子下方显示“—— 来源”；接口未返回来源时只显示正文。

### 位置与外观

- **显示位置**：选择页面顶部或底部。
- **字号**：面板可在 8—48 px 之间调节。
- **透明度**：控制整个悬浮栏的可见程度；鼠标悬停时会临时变为完全不透明，方便阅读。
- **背景色与背景透明度**：颜色和 Alpha 值分开设置，可组合出轻或重的遮罩效果。
- **毛玻璃模糊**：控制悬浮栏背后的 `backdrop-filter` 模糊程度。
- **边距**：设置悬浮栏与页面顶部或底部之间的距离。
- **最大宽度**：按视口宽度百分比限制悬浮栏，避免长句横跨整屏。
- **切换动画**：开启后，新句子出现时使用短暂的淡入位移动画。

拖动字号、透明度、模糊、最大宽度和背景透明度滑块时，面板会实时显示当前数值；点击“保存”后才会写入完整配置并应用到悬浮栏。

## 站点匹配：决定它在哪里出现

设置面板底部会显示当前域名及“已启用 / 已禁用”状态，并提供三种模式：

### 全站通用

默认模式。脚本在所有允许用户脚本运行的普通网页中显示，域名列表在此模式下不参与判断。

### 仅指定站点

白名单模式。只有匹配域名列表的站点才显示一言。例如只想在 GitHub 和其子域名使用：

```text
github.com
*.github.com
```

### 排除指定站点

黑名单模式。除列表中的站点外，其余网页都显示一言。例如不想让它覆盖在线会议和视频站点的控件：

```text
meet.example.com
video.example.com
*.video.example.com
```

域名可以每行填写一个，也可以使用逗号或分号分隔。匹配不区分大小写，并支持 `*` 通配符。

需要注意：`example.com` 只匹配根域名，`*.example.com` 只匹配带子域名的地址。若两者都要覆盖，请各写一行：

```text
example.com
*.example.com
```

“添加当前站点”会把正在访问的域名补入列表，且不会重复添加；“清空列表”只清除输入框内容，仍需点击“保存”才能应用。白名单为空时不会在任何站点显示，黑名单为空时则等同于全站启用。

## 三套实用配置

### 安静阅读

- 分类：文学或诗词
- 自动刷新：120 秒
- 位置：底部
- 透明度：0.7
- 显示来源：开启
- 动画：开启

适合长文阅读。较低透明度和较长刷新间隔不会频繁打断注意力。

### 工作陪伴

- 分类：哲学或全部分类
- 自动刷新：300 秒
- 位置：顶部
- 最大宽度：60%
- 站点模式：仅指定站点

把常用工作站点加入白名单，只在需要的网页里保留一言。

### 全站使用但避开关键页面

- 自动刷新：30 秒
- 站点模式：排除指定站点
- 将在线会议、网银、表单后台和全屏视频站点加入黑名单

这能保留“随处偶遇一句话”的体验，又避免悬浮栏遮挡对位置敏感的网页控件。

## 常见问题排查

### 安装后没有出现悬浮栏

按以下顺序检查：

1. 当前页面是否是浏览器内部页、扩展商店或其他禁止脚本注入的页面。
2. 用户脚本管理器及本脚本是否已启用。
3. 安装后是否刷新了已经打开的网页。
4. 在扩展菜单中执行“开关一言”，确认总开关不是关闭状态。
5. 打开“一言设置”，查看当前站点状态与匹配模式；尤其注意空白名单会禁用全部站点。
6. 检查浏览器是否只允许扩展“点击时运行”，或是否限制了它访问当前站点。

### 一直显示网络错误或请求超时

脚本需要访问 `https://v1.hitokoto.cn/`。请确认网络、代理、DNS、广告拦截器或隐私扩展没有阻断该域名。请求超过 8 秒会主动显示超时提示，网络恢复后单击悬浮栏即可重试。

### 悬浮栏遮挡网页按钮

先切换到另一侧，再适当增大边距或减小最大宽度。若某类网站布局固定，最省心的办法是把它加入黑名单。

### 设置保存后丢失

配置通过 `GM_setValue` 保存在当前浏览器配置文件和当前用户脚本管理器中。无痕窗口、清理扩展数据、换浏览器或更换浏览器配置文件后，设置可能不会自动迁移。

### 单页应用切换页面后消失

脚本会监测文档根节点下的内容变化，在悬浮栏被移除或整个页面主体被替换时尝试恢复；请求中重建的悬浮栏也能接收返回结果。少数采用特殊渲染或封闭 Shadow DOM 的站点仍可能不兼容；可刷新页面，或将该站点加入排除列表。

## 权限与隐私说明

安装确认页会展示脚本所需权限。它们各自用于：

- `GM_xmlhttpRequest`：跨域请求 Hitokoto API，避免受到网页自身跨域策略限制
- `GM_addStyle`：注入悬浮栏与设置面板样式
- `GM_setValue` / `GM_getValue`：在本地保存和读取设置
- `GM_registerMenuCommand`：向脚本管理器菜单添加设置、换句和开关入口
- `@connect v1.hitokoto.cn`：把网络访问范围声明为一言接口
- `@match *://*/*`：让“全站通用”和站点黑白名单成为可能
- `@noframes`：只在顶层页面运行，避免在页面内的每个 iframe 重复显示

脚本不会读取表单内容、账号信息或网页正文，也不会把当前网址作为参数发送给一言接口。每次加载或换句会向第三方 Hitokoto API 发起网络请求；该服务仍会像其他网络服务一样接收到完成请求所必需的网络信息，请按自己的隐私偏好决定是否使用。

接口返回的句子与来源会先进行 HTML 转义，再写入悬浮栏，避免远端文本被当作页面代码执行。

## 更新、停用与卸载

- **临时停用**：使用扩展菜单中的“开关一言”，或在脚本管理器中关闭本脚本。
- **仅停用某个网站**：使用“在当前站点禁用”，或在设置中维护黑名单。
- **更新脚本**：重新点击本文的“下载”入口，在脚本管理器确认覆盖安装。相同脚本标识下，本地设置通常会继续保留。
- **彻底卸载**：打开用户脚本管理器的控制面板，找到“一言 · 全站通用版”，选择删除。是否同时清除脚本存储取决于管理器实现。

## 实现细节

脚本以一个固定定位的 `div` 作为悬浮栏，通过 CSS 变量应用外观配置；句子由 Hitokoto JSON API 提供。自动刷新使用单一定时器，每次配置变化都会先清理旧定时器再按新间隔创建，避免重复刷新。

请求过程用活动请求标识防止并发，并分别处理成功、网络错误、超时和 JSON 解析失败。配置变化或停用时会使旧请求失效并尝试取消，旧回调不会恢复已停用的悬浮栏。站点规则会先把通配符转换为带首尾边界的正则表达式，再与 `location.hostname` 匹配。SPA 兼容由 `MutationObserver` 负责：页面重绘后重建悬浮栏；若请求仍在进行，则复用该请求并把结果写入当前节点。

它刻意不接管页面、不收集阅读行为，也不做复杂推荐。它只做一件小事：在你经过网页时，递来一句话。
