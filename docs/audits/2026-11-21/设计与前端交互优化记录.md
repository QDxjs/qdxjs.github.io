# 设计与前端交互优化记录

日期：2026-11-21（Asia/Singapore）

范围：在现有纸本配色、品牌字体和静态博客结构内落实设计与前端评估中的 15 项建议。保留正式内容与演示内容的边界，不补写未经提供的作者经历。

## 逐项实施

| 编号 | 原问题 | 本次处理 |
| --- | --- | --- |
| D1 | 首页三栏平均用力，缺少阅读起点 | 在栏目之前增加一条正式内容推荐；仅从 `demo: false` 的条目选择，优先 `featured`，否则使用现有稳定顺序。当前展示一言作品。 |
| D2 | 作品封面只有渐变和重复标题 | 为作品增加可选站内 `cover`（图片、替代文本、宽高）数据。一言复用纯色背景的真实运行截图，保持完整画面；未配置图片的演示作品保留原样。 |
| D3 | 作者识别偏装饰，演示内容较多 | 首屏优先真实作品与操作入口，保留“演示内容”和简介未核实说明。没有编造个人经历，也没有把演示项目改为真实成果；真实个人简介仍须作者提供。 |
| D4 | 阅读与操作字体分工不清 | 新增系统 UI 字体变量，用于导航、操作、日期说明和辅助信息；品牌、标题、正文及代码保留各自字体系。 |
| D5 | 标签、徽标、日期等字号偏小 | 核心列表、搜索、文章元信息与目录辅助文字提高至至少 14 px（根字号 16 px 时）；保留既有代码字号及颜色对比修复。 |
| D6 | 重复卡片与徽标削弱层次 | 首页将推荐与后续栏目分层，避免推荐条目在下方选择中重复；内容说明改为普通说明文字。保留必要演示标记，单页不显示无效分页。 |
| F1 | 移动菜单打开后键盘容易越过链接 | 响应式调整导航 DOM 位置并在展开时聚焦首链接；保留 Escape 关闭返焦，桌面恢复原 Tab 顺序。 |
| F2 | 切换标签会丢失当前栏目 | 标签选择从当前 URL 派生，保留 `section` 及其他参数，只更新标签并重置 `page=1`。 |
| F3 | 封面有卡片悬停效果却不可点击 | 封面、标题、摘要与阅读提示放在同一个原生主链接内；标签保留独立链接，避免嵌套链接。 |
| F4 | 搜索只过滤、不按相关性排序 | 按最强命中字段排序：标题、标签、摘要、来源、正文；同级保留索引原顺序。保留安全文本渲染、错误重试、陈旧响应隔离及返回状态恢复。 |
| F5 | 正文尚未开始，进度已前进 | 根据正文的实际滚动区间计算，从正文起点 0% 到末段视窗 100%；短文采用正文经过阅读线的距离并受页面终点约束，不可滚动页面保持 0%。 |
| F6 | 移动端阅读长文途中难以再开目录 | 仅在超过两屏且已进入阅读的长文显示“本文目录”按钮；复用原生折叠目录作为轻量浮层，提供 Escape、返焦、标题跳转及占位以保持滚动位置。 |
| F7 | 单页列表仍显示分页 | SSR 和客户端均在零页、单页时隐藏分页。 |
| F8 | 标签索引入口隐蔽 | 首页增加按标签浏览，栏目列表增加“浏览全部标签”，后者带入当前栏目。 |
| F9 | 代码缺少复制操作 | 在 `pre` 之前增加复制按钮及 live 状态反馈，复制 `code.textContent`，成功和权限拒绝均有提示；不改变 Shiki 标记和代码原文。 |
